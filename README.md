# Jeevan Rao R — Personal Portfolio Website

A modern, high-performance personal portfolio website built with **React**, **Vite**, and modern responsive CSS design architecture for **Jeevan Rao R** — Computer Science and Engineering student and aspiring Frontend Developer / UI/UX Designer.

## 🚀 Live Preview & Quick Start

### 1. Installation
```bash
npm install
```

### 2. Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
